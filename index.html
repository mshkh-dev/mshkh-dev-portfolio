What I’ve been building

Three things I made to find out how they work.

sloth-daemon

Every Linux user has watched one runaway process eat the whole machine. The usual fix is to kill it. I wanted something gentler.

sloth-daemon watches CPU use through eBPF, asks a small local model running on Ollama what kind of process it is looking at, then slows it down with cgroup v2 instead of ending it. It’s written in Rust with aya.

Read the code →

AcciVision-AI

A camera watches the road, and a CNN+LSTM model watches the camera. The CNN reads each frame, the LSTM keeps track of what happens across frames, and when the sequence looks like an accident the system raises an alert on a Flask monitoring dashboard.

It’s an end-to-end, real-time pipeline, from video in to alert out.

Read the code →

Warehouse Robot Path Planning

My third-year mini project asks a simple question: how should a robot cross a warehouse floor?

I implemented A*, Dijkstra and breadth-first search in Python and compared how each one explores the same floor. Watch them take turns on the right. The repository is on its way.
